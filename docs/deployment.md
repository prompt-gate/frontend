# Deployment

This application is published as a Docker image through GitHub Container
Registry.

## Official Image

```text
ghcr.io/prompt-gate/frontend
```

The image exposes port `3000` and runs the Nitro server generated by
`npm run build`.

## Runtime Configuration

The following variable must point to the Prompt Gate backend:

```sh
NUXT_PUBLIC_API_BASE_URL=https://api.example.com
```

Nuxt reads this value through `runtimeConfig.public.apiBaseUrl`. Without it,
backend authentication stays disabled on the frontend.

See [Environment variables](environment.md) for the complete variable reference.

## Local Build

```sh
npm ci
npm run typecheck
npm test -- --run
npm run build
```

To preview the Nuxt output locally:

```sh
npm run preview
```

## Build Docker

```sh
docker build -t prompt-gate-frontend:test .
```

Run the image locally:

```sh
docker run --rm \
  -p 3000:3000 \
  -e NUXT_PUBLIC_API_BASE_URL=http://localhost:8080 \
  prompt-gate-frontend:test
```

The application is then available at `http://localhost:3000`.

## Container Security

The container does not run as root. The Node process runs as:

```text
user: appuser
uid: 1000
gid: 1000
```

Quick verification:

```sh
docker run --rm --entrypoint id prompt-gate-frontend:test
```

The expected output must contain `uid=1000(appuser)`.

## Deploy from GHCR

Example run command for a published release:

```sh
docker pull ghcr.io/prompt-gate/frontend:v0.1.0
docker run --rm \
  -p 3000:3000 \
  -e NUXT_PUBLIC_API_BASE_URL=https://api.example.com \
  ghcr.io/prompt-gate/frontend:v0.1.0
```

In production, prefer a versioned tag (`vX.Y.Z`) over `latest`.
